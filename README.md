# СмартКредит — Цифровой кредитный конвейер для МСП

Прототип облачного решения для малого и микробизнеса, объединяющий клиентский путь и внутреннюю обработку заявок в едином цифровом продукте.

## Быстрый старт

Убедитесь, что у вас установлен Docker Desktop. Запустите сборку из корня проекта:
cd Полный_путь_до_папки_проекта
docker compose up --build -d

### Доступные сервисы после запуска:

| Сервис | URL |
| :--- | :--- |
| Клиентский сайт | http://localhost:8080 |
| Кабинет сотрудника банка | http://localhost:8080/bank.html |
| Swagger (Оркестратор) | http://localhost:8002/docs |
| Swagger (Моки) | http://localhost:8001/docs |

## Архитектура проекта

* **Frontend (Nginx :8080):** Клиентский интерфейс и кабинет банка (HTML/JS/CSS).
* **Orchestrator (FastAPI :8002):** Бизнес-логика, расчет скоринга (XAI), работа с базой данных (SQLite).
* **Mocks (FastAPI :8001):** Локальные симуляторы внешних проверок (ЕГРЮЛ, ФНС, БКИ, ЗСК).

## Ключевые реализованные фичи

1. **Explainable AI (XAI) - Прозрачный скоринг:** Система не просто выдает "Одобрено/Отказано", а строит детальный отчет о том, из чего сложился балл (6 категорий с прогресс-барами). Это снижает нагрузку на поддержку и повышает доверие клиента.
2. **Отказоустойчивость (Fault Tolerance):** Если внешний сервис (например, БКИ) падает с ошибкой 403 или таймаутом, конвейер не ломается с ошибкой 500. Заявка автоматически уходит в статус `MANUAL_REVIEW` в кабинет банка для ручного разбора.
3. **Risk-Based Pricing (Математическая модель):** Ставка, сумма и пени рассчитываются динамически на основе накопленного балла (Грейды A+, A, B, C). Надежные клиенты получают 14%, рискованные — 23.5% и урезанную сумму.
4. **Zero-Touch Data Enrichment:** Клиенту достаточно ввести только ИНН. Система сама подтягивает название компании, ОГРН, ФИО директора и финансовые показатели из государственных реестров.
5. **Полноценный Back-Office (B2B):** Реализован отдельный интерфейс для сотрудника банка (`bank.html`). Банкир видит сырые JSON-ответы от всех проверок и может принять ручное решение по зависшей заявке.
6. **Gatekeeping:** Жесткий контроль доступа. Клиент не может подать заявку, не авторизовавшись, а поле ИНН блокируется, исключая подмену данных.

## Бизнес-ценность
* **Снижение времени на выдачу кредита:** Автоматический сбор данных из 5 источников и скоринг занимают менее 3 секунд.
* **Снижение рисков:** Внедрены жесткие стоп-факторы (ликвидация, банкротство учредителя, красная зона ЗСК), которые отсекают проблемных клиентов до траты денег на запросы в БКИ.
* **Масштабируемость:** Микросервисная архитектура (Frontend, Orchestrator, Mocks) готова к развертыванию в Kubernetes и замене мок-сервисов на реальные банковские API без изменения бизнес-логики.
